# ระเบิดเวลาคำคล้องจอง 💣
เว็บเกมการศึกษาภาษาไทย พัฒนาโดย ครูนนทพัทธ์ หิรัญเรือง · โรงเรียนกระดุมทองวิทยา
เป็นเว็บสถิต (HTML/JS) deploy บน **GitHub Pages** ได้ทันที · คลังคำและบันทึกคะแนนใช้ **Google Sheets** (ผ่าน Apps Script) · ห้องเล่นสดใช้ **Firebase Firestore**

## 3 โหมดการเล่น
| โหมด | ใช้อะไร | หมายเหตุ |
|---|---|---|
| 1 แบ่งทีมระเบิดเวลา | จอครูจอเดียว | 2–6 ทีม สุ่มส่งระเบิด พิมพ์คำตอบของทีม ระบบตรวจสัมผัสให้ ถ้าไม่แน่ใจครูตัดสิน |
| 2 ตอบสดพร้อมกันทั้งห้อง | จอครู + มือถือนักเรียน (สแกน QR) | คะแนนตามความเร็ว + โบนัสตอบถูกติดกัน + ตารางคะแนนแบบ Kahoot |
| 3 ต่อคำเวียนรายคน | จอครูจอเดียว | คีย์ลัด Space=ผ่าน, B=ระเบิด, P=หยุด, H=เฉลย |

## ติดตั้งใช้งาน (ทำครั้งเดียว)
### 1) Google Sheets + Apps Script (คลังคำ/บันทึกคะแนน)
1. สร้าง Google Sheets ใหม่ → ส่วนขยาย → Apps Script → วางโค้ดจาก `gas/Code.gs`
2. เลือกฟังก์ชัน `setup` → เรียกใช้ 1 ครั้ง (อนุญาตสิทธิ์) จะได้แผ่นงาน **คลังคำ / บันทึกคะแนน / สรุปกิจกรรม** พร้อมคำตัวอย่าง
3. ทำให้ใช้งานได้ → เว็บแอป → เรียกใช้ในฐานะ “ฉัน”, ผู้มีสิทธิ์เข้าถึง “ทุกคน” → คัดลอก URL ที่ลงท้าย `/exec`
4. ใส่ URL ใน `js/config.js` ที่ `GAS_URL`

**แผ่นงานคลังคำ**: คอลัมน์ `คำโจทย์ | คำสัมผัสที่ถูกต้อง (คั่น ,) | ตัวเลือกหลอก (คั่น ,) | ระดับ 1-3 | หมวด | เปิดใช้` — ครูเพิ่ม/แก้ได้เอง แล้วกด “🔄 โหลดคลังคำใหม่” ที่หน้าหลัก
> ตัวเลือกหลอกควรมีอย่างน้อย 3 คำ ระบบจะตัดตัวเลือกหลอกที่ “สัมผัสจริง” ออกให้อัตโนมัติ (ใช้ตรรกะตรวจสัมผัสจากเครื่องมืออินทรวิเชียรฉันท์ ๑๑)

### 2) Firebase (เฉพาะโหมด 2)
1. console.firebase.google.com → สร้างโปรเจกต์ → Build → **Firestore Database** → สร้าง (โหมด production)
2. Project settings → Your apps → Web → คัดลอก `firebaseConfig` ไปใส่ `FIREBASE` ใน `js/config.js`
3. Firestore → Rules วางกฎนี้ แล้ว Publish (ห้องเล่นเป็นข้อมูลชั่วคราวระหว่างคาบเรียน)
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /rooms/{room}/{document=**} { allow read, write: if true; }
  }
}
```
> ยังไม่ตั้งค่า Firebase = โหมดทดลองในเครื่องเดียว (เปิดหน้า `play.html?pin=…` ในแท็บอื่นของเบราว์เซอร์เดียวกัน) ใช้ทดสอบได้ แต่ใช้จริงกับมือถือนักเรียนไม่ได้

### 3) GitHub Pages
อัปโหลดทั้งโฟลเดอร์ (ยกเว้น `_raw_chatgpt` ถ้าไม่ต้องการ) ขึ้น repo → Settings → Pages → Deploy from branch → `main` / root
แล้วใส่ URL ของหน้าเว็บใน `SITE_URL` ของ `js/config.js` (เช่น `https://USERNAME.github.io/REPO/`) เพื่อให้ QR ชี้ถูกที่

css/style.css   js/{config,words-sample,rhyme,common,host,player}.js
gas/Code.gs     assets/{img,sfx,music}

- เสียงเอฟเฟกต์ 16 ไฟล์ใน `assets/sfx` (tick, tock, explosion, correct, wrong ฯลฯ)
- ภาพต้นฉบับจาก ChatGPT อยู่ใน `assets/_raw_chatgpt`
